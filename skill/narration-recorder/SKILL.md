# 逐句錄音：幫使用者斷句並送進工具

## 1. 找到工具、確認有在跑
- 工具資料夾：有 `server.py` 和 `push.py` 的那個資料夾（通常是安裝時 clone 下來的 `narration-recorder/`）。找不到就問使用者放在哪。
- 檢查：`curl -s http://127.0.0.1:8780/api/projects`。沒回應就在背景啟動：`python3 <工具資料夾>/server.py`（會自動打開瀏覽器）。

## 2. 決定每次錄多長
使用者沒說就問一次，之後沿用：

| 模式 | 一行大約 | 適合 |
|---|---|---|
| 短句 | 8 到 15 字 | 一口氣一句，最不容易唸錯 |
| 一般 | 15 到 25 字 | 一個完整句子 |
| 長句 | 25 到 40 字 | 兩三句連著講，語氣連貫 |
| 整段 | 照原稿段落 | 習慣一次講一大段 |

## 3. 斷句規則
1. 照講話換氣的位置切，長度照上面的模式
2. 不要把數字、英文詞、專有名詞切開（「Claude Code」「1,700 公尺」要在同一行）
3. 拿掉括號裡的畫面說明、出處標記（例如【示意】〔A〕（畫面：…））
4. 不改字、不加字，保留原本標點
5. 太短的（3 個字以內，例如「好，」）併進下一句

## 4. 送進工具
把結果一行一句寫進暫存檔，執行：
```
python3 <工具資料夾>/push.py "影片名稱" 暫存檔.txt --script 原稿檔
```
成功會印出「<資料夾名> N 句」。

## 5. 告訴使用者
請他打開 http://localhost:8780 ，點「最近的稿子」裡剛建好的那份就能開始錄。斷句不滿意可以在錄音頁「設定 → 調整斷句」改，字沒改到的句子錄音會保留。
